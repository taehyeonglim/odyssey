# 🏛️ 호메로스 대서사시: 《일리아드》 & 《오디세이아》 인터랙티브 아카이브
> **Homer's Epics: The Iliad & The Odyssey — Interactive Classical Archive (Master Edition)**

서양 고전문학의 불멸의 원천인 호메로스(Homer)의 양대 서사시 **《일리아드(Iliad)》**와 **《오디세이아(Odyssey)》**의 장대한 서사를 탐험할 수 있는 현대적인 반응형 인터랙티브 웹 애플리케이션입니다.

모든 시각 회화 삽화는 **Gemini AI 이미지 생성 모델**을 통해 고전 유화 명화풍(Caravaggio, Waterhouse, Jacques-Louis David 화풍)으로 제작되었습니다.

## 📖 상세 사용 설명서 (User Manual)

### 1. ⚔️ 《일리아드》 모드 (The Iliad)
- **24권 연대기 타임라인 & 완독 트래커 (Reading Tracker)**:
  - 아킬레우스의 분노(1권)부터 헥토르와의 결투(22권), 프리아모스의 탄원과 장례(24권)까지 수록.
  - **완독 체크 & 프로그레스 바**: 권별 완독 상태를 기록하고 진척도를 실시간 트래킹.
  - **서사 낭독 (Web Speech TTS)**: 각 권의 줄거리와 핵심 명대사를 음성으로 낭독.
- **🛡️ 아킬레우스의 신성한 방패 (The Shield of Achilles)**:
  - 《일리아드》 제18권 헤파이토스의 걸작을 **동심원 인터랙티브 SVG 인포그래픽**으로 구현. 8대 영역(우주, 평화의 도시, 전쟁의 도시, 밭갈이, 수확, 포도밭 노래, 사자 사냥, 오케아노스 대양) 탐색.
- **⚔️ 트로이아 전장 전술 맵 (Battlefield Tactics Map)**:
  - 함선 진지 ➔ 스카만드로스 강 ➔ 대평원 ➔ 스카이아 성문까지의 4대 격전지 지형 및 일대일 결투 분석.

---

### 2. 🧭 《오디세이아》 모드 (The Odyssey)
- **지중해 인터랙티브 항해 지도 (Interactive Mediterranean Map)**:
  - 트로이 출항(1)부터 이타카 귀환(14)까지 **14개 기착지 웨이포인트**.
  - **자동 항해 재생(Auto-Play)** 시뮬레이션 및 항해 진행률(%), 바다 위험 구역(스킬라, 세이렌) 시각화.

---

### 3. 🛡️ 호메로스 인물 도감 & 2인 스탯 비교 (Character Codex)
- **2인 영웅 스탯 비교 모드 (Comparison Mode)**: 두 영웅을 선택하여 용맹, 지혜, 운명, 신의 가호 능력치를 1:1 비교.
- 아킬레우스, 오디세우스, 아테나, 헥토르 등 8대 인물 상세 프로필 및 별칭(Epithet).

---

### 4. 🌳 영웅 가계도 & 인물 관계망 (Genealogy Graph)
- **4대 왕가 계보도**: 아트레우스 가문, 프리아모스 왕가, 펠레우스 가문, 아르케이시오스 가문.
- 3개 세대별 인물 카드 및 숙명적 최후, 부부/자녀/라이벌 관계 시각화.

---

### 5. 📖 호메로스 고대 그리스어 개념 사전 (Homeric Lexicon)
- **12대 핵심 사상**: 메니스, 클레오스, 노스토스, 크세니아, 폴뤼트로포스, 모이라, 휘브리스, 아레테 등.
- **플래시카드 암기 모드** 및 **단어장 북마크(★) 기능**.

---

### 6. ⚔️ 영웅 가상 결투장 (Epic Duel Arena)
- 영웅들의 고유 필살기(펠리온의 창, 성채의 결사항전, 번개 지략 등)와 4대 스탯 기반 턴제 백병전 시뮬레이션.
- 실시간 서사시 전투 로그 및 최근 5회 전적 히스토리.

---

### 7. 📜 명대사 카드 & 플로팅 액션 바 (Floating Action Deck)
- 6대 불멸의 명대사 프리셋 갤러리 및 클립보드 원클릭 복사.
- 좌측 하단 플로팅 툴바(빠른 최상단 이동, 통합 검색, 명대사 모음).
- `Cmd+K` 전역 통합 검색 모달.
- 3가지 무드(평온, 전운, 신비) Web Audio API 사운드스케이프.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 사용 기술 |

## 💻 로컬 개발 및 실행 방법 (Local Development)

```bash
# 1. 저장소 클론
git clone https://github.com/taehyeonglim/odyssey.git
cd odyssey

# 2. 패키지 설치
npm install

# 3. 개발 서버 실행 (http://localhost:5173)
npm run dev

# 4. 무결성 검증 테스트
node scripts/verify_integrity.cjs

# 5. 프로덕션 빌드
npm run build
```
