# 🏛️ 호메로스 대서사시: 《일리아드》 & 《오디세이아》 인터랙티브 아카이브
> **Homer's Epics: The Iliad & The Odyssey — Interactive Classical Archive (Masterpiece Edition)**

서양 고전문학의 불멸의 원천인 호메로스(Homer)의 양대 서사시 **《일리아드(Iliad)》**와 **《오디세이아(Odyssey)》**의 장대한 서사를 탐험할 수 있는 현대적인 반응형 인터랙티브 웹 애플리케이션입니다.

영웅 도감 및 서사시 갤러리의 모든 시각 회화 삽화는 고전 유화 명화풍(Caravaggio, Waterhouse, Jacques-Louis David 화풍)의 고해상도 초상화 및 장면화로 완비되어 있습니다.

## 📖 상세 기능 설명서 (Comprehensive Feature Guide)

### 1. ⚔️ 《일리아드》 모드 (The Iliad)
- **24권 연대기 타임라인 & 완독 트래커 (Reading Tracker)**:
  - 아킬레우스의 분노(1권)부터 헥토르와의 결투(22권), 프리아모스의 탄원과 장례(24권)까지 전 권 수록.
  - **완독 체크(✔)**: 각 권의 완독 여부를 클릭하여 체크하고 진척률(%)을 실시간으로 확인 (브라우저 `localStorage` 저장).
  - **서사 낭독 (Web Speech TTS)**: 각 권의 줄거리와 핵심 구절을 한국어 음성으로 낭독.
- **🛡️ 아킬레우스의 신성한 방패 (The Shield of Achilles)**:
  - 《일리아드》 제18권 헤파이토스의 걸작을 **동심원 인터랙티브 SVG 인포그래픽**으로 시각화.
  - 8대 영역(우주 중심부, 평화의 도시, 전쟁의 도시, 밭갈이, 밀 수확, 포도밭 소년의 리라 노래, 사자 사냥, 외곽 오케아노스의 대양)을 클릭하여 원문 인용 및 문학적 상징 분석 열람.
- **⚔️ 트로이아 전장 전술 맵 (Battlefield Tactics Map)**:
  - 그리스 함선 진지 ➔ 스카만드로스 강변 격전지 ➔ 트로이아 대평원 ➔ 스카이아 성문 앞 결투장까지의 4대 격전지 지형 분석 및 올림포스 신들의 개입 시각화.
- **진영 대치도 (Achaeans vs Trojans vs Gods)**:
  - 그리스 연합군 vs 트로이아 방어군 vs 올림포스 신들의 대의명분 및 주요 영웅 비교.

---

### 2. 🧭 《오디세이아》 모드 (The Odyssey)
- **지중해 인터랙티브 항해 지도 (Interactive Mediterranean Map)**:
  - 트로이 출항(1)부터 이타카 귀환(14)까지 **14개 기착지 웨이포인트**.
  - **자동 항해 재생(Auto-Play)**: 배가 이동하며 순차적으로 사건을 시뮬레이션.
  - **바다 위험 구역 레이블**: 스킬라와 카리브디스 해협, 세이렌 암초 등 바다의 위험 요소를 지도상에 표기.
  - **기착지 상세 모달**: Gemini 일러스트, 마주한 시련, 오디세우스의 지략(Polymetis), 인명 피해/결과 통계 수록.

---

### 3. 🛡️ 호메로스 인물 도감 & 1:1 비교 (Character Codex)
- **8대 영웅 전원 고해상도 초상화 탑재**: 아킬레우스, 오디세우스, 아테나, 헥토르, 페넬로페, 키르케, 폴리페모스, 아가멤논.
- **2인 영웅 스탯 비교 모드 (Hero Comparison Mode)**:
  - 원하는 두 영웅을 선택하여 용맹(Bravery), 지혜(Wisdom), 운명(Destiny), 신의 가호(Divine Favor) 4대 능력치를 나란히 1:1 비교.

---

### 4. 🌳 영웅 가계도 & 인물 관계망 (Genealogy Graph)
- **4대 왕가 계보도**: 아트레우스 가문, 프리아모스 왕가, 펠레우스 가문, 아르케이시오스 가문.
- 3개 세대별(선조/부모, 트로이 영웅, 전후 자녀) 인물 카드 및 숙명적 최후, 부부/자녀/라이벌 관계선 시각화.

---

### 5. 📖 호메로스 고대 그리스어 개념 사전 (Homeric Lexicon)
- **12대 핵심 사상**: 메니스(분노), 클레오스(영광), 노스토스(귀향), 크세니아(환대), 폴뤼트로포스(지략), 모이라(운명), 휘브리스(오만), 아레테(탁월함) 등.
- **플래시카드 암기 모드** 및 **단어장 북마크(★)**, Web Speech TTS 음성 낭독.

---

### 6. ⚔️ 영웅 가상 결투장 (Epic Duel Arena)
- 아킬레우스, 헥토르, 디오메데스, 파리스, 오디세우스 등 2인의 영웅을 선택하여 턴제 백병전 시뮬레이션 진행.
- 영웅별 고유 필살기(펠리온의 창, 성채의 결사항전, 번개 지략 등) 및 실시간 서사시 전투 로그, 최근 5회 전적 히스토리.

---

### 7. 🏆 영웅의 선택 & 호메로스 학당 (Trials & Academy)
- **영웅의 선택 (Hero Trial)**: 키클롭스 동굴 탈출, 세이렌의 유혹, 스킬라와 카리브디스의 딜레마 등 3단계 텍스트 어드벤처.
- **호메로스 학당 (Trivia Challenge)**: 서사시의 어원과 명장면에 관한 10단계 퀴즈 및 칭호(올림포스의 현자 등) 획득.

---

### 8. 📜 명대사 카드, 플로팅 툴바 & 사운드스케이프
- **명대사 카드 모음 (Quote Card Deck)**: 6대 명대사 프리셋 및 클립보드 복사 & TTS 낭독.
- **플로팅 액션 도크 (Floating Action Deck)**: 화면 좌측 하단 상단 스크롤(Back-to-Top), 통합 검색, 명대사 카드 모음 빠른 접근 버튼.
- **전역 통합 검색 (`Cmd+K` / `Ctrl+K`)**: 타임라인, 기착지, 방패 구역, 인물, 그리스어 개념 즉시 검색.
- **3단 무드 사운드스케이프 (Web Audio API)**: 평온한 에게해 / 트로이아 전운 / 세이렌의 미혹.

## 💻 로컬 개발 및 실행 방법 (Local Development)

```bash
# 1. 저장소 클론
git clone https://github.com/taehyeonglim/odyssey.git
cd odyssey

# 2. 패키지 설치
npm install

# 3. 개발 서버 실행 (http://localhost:5173)
npm run dev

# 4. 무결성 검증 테스트
node scripts/verify_integrity.cjs

# 5. 프로덕션 빌드
npm run build
```
