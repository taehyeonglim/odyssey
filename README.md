# 🏛️ 호메로스 대서사시: 《일리아드》 & 《오디세이아》 인터랙티브 아카이브
> **Homer's Epics: The Iliad & The Odyssey — Interactive Classical Archive**

서양 고전문학의 불멸의 원천인 호메로스(Homer)의 양대 서사시 **《일리아드(Iliad)》**와 **《오디세이아(Odyssey)》**의 장대한 서사를 탐험할 수 있는 현대적인 반응형 인터랙티브 웹 애플리케이션입니다.

모든 시각 회화 삽화는 **Gemini AI 이미지 생성 모델**을 통해 고전 유화 명화풍(Caravaggio, Waterhouse, Jacques-Louis David 화풍)으로 제작되었습니다.

## 📖 상세 사용 설명서 (User Manual)

### 1. ⚔️ 《일리아드》 모드 (The Iliad)
- **24권 연대기 타임라인 (Timeline Viewer)**:
  - 아킬레우스의 분노(1권)부터 헥토르와 안드로마케의 작별(6권), 파트로클로스의 전사(16권), 헥토르와의 결투(22권), 프리아모스의 탄원과 장례(24권)까지 수록.
  - **명장면 필터링**: '주요 명장면만 보기' 버튼으로 핵심 분기만 집중 열람 가능.
  - **그리스어 원문 & 번역**: 각 권의 대표 명대사를 고대 그리스어 원문과 한국어 번역으로 확인.
- **🛡️ 아킬레우스의 신성한 방패 (The Shield of Achilles)**:
  - 《일리아드》 제18권에 등장하는 헤파이토스의 걸작을 **동심원 인터랙티브 SVG 인포그래픽**으로 구현.
  - 방패의 8대 영역(우주 중심부, 평화로운 도시, 전쟁의 도시, 밭갈이, 밀 수확, 포도밭 소년의 리라 노래, 사자 사냥, 외곽 오케아노스의 대양)을 클릭하여 문학적 상징과 묘사를 탐색.
- **⚔️ 트로이아 전장 전술 맵 (Battlefield Tactics Map)**:
  - 그리스 함선 진지 ➔ 스카만드로스 강 ➔ 트로이아 대평원 ➔ 스카이아 성문까지의 4대 격전지 지형 분석.
  - 구역별 주요 결투, 신들의 개입, 전세(공방 흐름) 시각화.
- **진영 대치도 (Achaeans vs Trojans vs Gods)**:
  - 그리스 연합군 vs 트로이아 방어군 vs 올림포스 신들의 대의명분 및 주요 영웅 비교.

---

### 2. 🧭 《오디세이아》 모드 (The Odyssey)
- **지중해 인터랙티브 항해 지도 (Interactive Mediterranean Map)**:
  - 트로이 출항(1)부터 키코네스, 로토파고스, 키클롭스, 아이올리아, 식인거인, 키르케, 하데스 저승, 세이렌, 스킬라와 카리브디스, 태양신의 소, 칼립소, 파이아케스, 이타카 귀환(14)까지 **14개 기착지 웨이포인트**.
  - **자동 항해 재생(Auto-Play)**: 재생 버튼을 누르면 배가 자동으로 14개 스테이션을 순차 이동하며 항해 시뮬레이션 진행.
  - **상세 분석 모달**: 각 기착지 핀을 클릭하면 Gemini 일러스트, 마주한 시련, 오디세우스의 지략(Polymetis), 인명 피해/결과 통계, 호메로스 원전 인용구를 열람.

---

### 3. 🛡️ 호메로스 인물 도감 (Character Codex)
- 아킬레우스, 오디세우스, 아테나, 헥토르, 페넬로페, 키르케, 폴리페모스, 아가멤논 등 주요 인물 프로필 수록.
- **필터 기능**: 서사시별(전체/일리아드/오디세이아) 및 진영별(그리스/트로이/올림포스/신화) 다중 필터링.
- **4대 능력치 레이더 바**: 용맹(Bravery), 지혜(Wisdom), 운명(Destiny), 신의 가호(Divine Favor) 시각화.
- 호메로스식 전통 별칭(Epithet) 및 문학적 의의 해설.

---

### 4. 🏆 영웅의 선택 & 호메로스 학당 (Interactive Trials & Academy)
- **영웅의 선택 시뮬레이터 (Hero Trial)**:
  - 키클롭스 동굴 탈출, 세이렌의 유혹, 스킬라와 카리브디스의 딜레마 등 3단계 텍스트 어드벤처.
  - 선택에 따라 지혜/용맹 점수와 생존 선원 수가 변동되며, 원전과의 일치 여부 및 대체 역사 해설 제공.
  - 모든 시련 완료 시 성적에 따른 호메로스 칭호 및 콘페티 폭죽 축하 효과.
- **호메로스 학당 퀴즈 (Homeric Trivia Challenge)**:
  - 서사시의 핵심 개념(메니스, 우티스, 몰리, 크세니아 등)과 명장면에 관한 10단계 퀴즈.
  - 즉각적인 원전 해설 및 최종 지식 등급(올림포스의 현자, 음유시인 랩소도스 등) 획득.

---

### 5. 🌊 3단 무드 사운드스케이프 (Web Audio API)
- 외부 음원 파일 없이 순수 브라우저 Web Audio API 신디사이저로 동작.
- 우측 하단 사운드 위젯을 통해 3가지 무드 선택 가능:
  1. **평온한 에게해 (Calm)**: 잔잔한 파도 소리와 고대 도리아 선법(Dorian mode) 리라 하프 아르페지오.
  2. **트로이아 전운 (Battle)**: 묵직한 전쟁 북소리와 고대 금관 나팔 공명음.
  3. **세이렌의 미혹 (Mystic)**: 몽환적인 신비의 배음 하모니.

---

### 6. 📜 명대사 카드 복사 도구 (Quote Card Tool)
- 호메로스의 불멸의 명대사를 고대 그리스어 원문과 한국어 번역이 담긴 소장용 카드로 확인하고 원클릭으로 클립보드에 복사하여 인용 및 공유 가능.

## 💻 로컬 개발 및 실행 방법 (Local Development)

```bash
# 1. 저장소 클론
git clone https://github.com/taehyeonglim/odyssey.git
cd odyssey

# 2. 패키지 설치
npm install

# 3. 개발 서버 실행 (http://localhost:5173)
npm run dev

# 4. 프로덕션 빌드
npm run build

# 5. 빌드 결과물 미리보기
npm run preview
```

## 🚀 GitHub Pages 배포 방식

본 프로젝트는 `.github/workflows/deploy.yml`을 통해 `main` 브랜치에 코드가 푸시될 때마다 GitHub Actions에서 자동으로 빌드 및 배포되도록 구성되어 있습니다.

```yaml
name: Deploy Odyssey Interactive to GitHub Pages
on:
  push:
    branches: ["main"]
```
