# 🏛️ 호메로스 대서사시: 《일리아드》 & 《오디세이아》 인터랙티브 아카이브
> **Homer's Epics: The Iliad & The Odyssey — Interactive Classical Archive (Phase 3)**

서양 고전문학의 불멸의 원천인 호메로스(Homer)의 양대 서사시 **《일리아드(Iliad)》**와 **《오디세이아(Odyssey)》**의 장대한 서사를 탐험할 수 있는 현대적인 반응형 인터랙티브 웹 애플리케이션입니다.

모든 시각 회화 삽화는 **Gemini AI 이미지 생성 모델**을 통해 고전 유화 명화풍(Caravaggio, Waterhouse, Jacques-Louis David 화풍)으로 제작되었습니다.

## 📖 상세 사용 설명서 (User Manual)

### 1. ⚔️ 《일리아드》 모드 (The Iliad)
- **24권 연대기 타임라인 (Timeline Viewer)**:
  - 아킬레우스의 분노(1권)부터 헥토르와의 결투(22권), 프리아모스의 탄원과 장례(24권)까지 수록.
  - **명장면 필터링**: '주요 명장면만 보기' 버튼으로 핵심 분기만 집중 열람 가능.
- **🛡️ 아킬레우스의 신성한 방패 (The Shield of Achilles)**:
  - 《일리아드》 제18권 헤파이토스의 걸작을 **동심원 인터랙티브 SVG 인포그래픽**으로 구현. 8대 영역(우주, 평화의 도시, 전쟁의 도시, 밭갈이, 수확, 포도밭 노래, 사자 사냥, 오케아노스 대양) 탐색.
- **⚔️ 트로이아 전장 전술 맵 (Battlefield Tactics Map)**:
  - 함선 진지 ➔ 스카만드로스 강 ➔ 대평원 ➔ 스카이아 성문까지의 4대 격전지 지형 및 일대일 결투 분석.
- **진영 대치도 (Achaeans vs Trojans vs Gods)**:
  - 그리스 연합군 vs 트로이아 방어군 vs 올림포스 신들의 대의명분 및 주요 영웅 비교.

---

### 2. 🧭 《오디세이아》 모드 (The Odyssey)
- **지중해 인터랙티브 항해 지도 (Interactive Mediterranean Map)**:
  - 트로이 출항(1)부터 이타카 귀환(14)까지 **14개 기착지 웨이포인트**.
  - **자동 항해 재생(Auto-Play)** 시뮬레이션 및 각 기착지별 스토리, 지략(Polymetis), 피해 통계 모달.

---

### 3. 🌳 영웅 가계도 & 인물 관계망 (Genealogy Graph)
- **4대 왕가 혈통 계보도**: 아트레우스 가문(미케네·스파르타), 프리아모스 왕가(트로이아), 펠레우스 가문(프티아), 아르케이시오스 가문(이타카).
- 세대별(선조, 영웅, 자녀) 인물 카드 및 숙명적인 최후와 가족 관계선 시각화.

---

### 4. 📖 호메로스 고대 그리스어 개념 사전 (Homeric Lexicon)
- **12대 핵심 사상**: 메니스(분노), 클레오스(영광), 노스토스(귀향), 크세니아(환대), 폴뤼트로포스(지략), 모이라(운명), 휘브리스(오만), 아레테(탁월함), 티메(명예), 네퀴이아(저승 하강) 등.
- **플래시카드 암기 모드**: 카드를 클릭하여 앞뒤를 뒤집으며 학습 가능.
- **음성 낭독 (Web Speech TTS)**: 개념 설명과 인용구 음성 청취 지원.

---

### 5. ⚔️ 영웅 가상 결투장 (Epic Duel Arena)
- 아킬레우스, 헥토르, 디오메데스, 파리스, 오디세우스 등 2인의 영웅을 선택하여 턴제 백병전 시뮬레이션 진행.
- 4대 능력치(용맹/지혜/운명/신의 가호) 기반 타격 판정 및 실시간 호메로스식 서사시 전투 로그 출력.

---

### 6. 🏆 영웅의 선택 & 호메로스 학당 (Trials & Academy)
- **영웅의 선택**: 키클롭스, 세이렌, 스킬라의 위기에서 내리는 3단계 분기 텍스트 어드벤처.
- **호메로스 학당**: 10문항 서사시 지식 퀴즈 및 칭호(올림포스의 현자 등) 획득.

---

### 7. 🔍 전역 통합 검색 (Omni Search / Cmd+K) & 🌊 3단 무드 사운드스케이프
- `Cmd+K` 단축키로 24권 타임라인, 14개 기착지, 방패 영역, 인물, 그리스어 개념 즉시 검색.
- 평온한 에게해 / 트로이아 전운 / 세이렌의 미혹 3가지 Web Audio 사운드스케이프 내장.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 사용 기술 |
| :--- | :--- |
| **Frontend Framework** | React 18, TypeScript, Vite |
| **Styling & Design** | Tailwind CSS (고대 그리스 테마), Lucide Icons |
| **Interactive Map & Visuals** | Custom Responsive SVG & Canvas |
| **Audio & Speech Engine** | Web Audio API (합성 신디사이저), Web Speech API (TTS) |
| **Interactive FX** | Canvas-Confetti (폭죽 효과) |
| **Image Generation** | Gemini AI Image Generation Model |
| **Hosting & CI/CD** | GitHub Pages & GitHub Actions |

## 💻 로컬 개발 및 실행 방법 (Local Development)

```bash
# 1. 저장소 클론
git clone https://github.com/taehyeonglim/odyssey.git
cd odyssey

# 2. 패키지 설치
npm install

# 3. 개발 서버 실행 (http://localhost:5173)
npm run dev

# 4. 무결성 검증 테스트
node scripts/verify_integrity.cjs

# 5. 프로덕션 빌드
npm run build
```
